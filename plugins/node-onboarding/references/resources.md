`/node-onboarding:resources` command.

[shared/team-info.md](../../node-team/skills/node/references/shared/team-info.md)
(sections Key Links, Slack Channels, Mailing List and Groups, Upstream
Communities). This file only adds bookmarks that are not listed there.
